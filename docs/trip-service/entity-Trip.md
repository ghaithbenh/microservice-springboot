## Generated table

```sql
create table trips (
    id                     bigint generated by default as identity,
    departure_station_id   bigint not null,
    destination_station_id bigint not null,
    louage_id              bigint not null,
    price_per_seat         float(53) not null,
    seats_taken            integer not null,
    status                 varchar(20) not null,
    primary key (id)
);
```

⚠️ Note there are **no foreign keys** — `louageId` is just a bigint. The database cannot
guarantee the referenced rows exist in the other services' databases.

## The intended `@Transient` enrichment (missing)

The project TODO says the entity should also expose the *resolved* objects, not only ids:

```java
@Transient                            // Hibernate ignores it: not a column
private LouageDto louage;             // filled from louage-service via Feign
@Transient
private StationDto departureStation;  // filled from station-service
@Transient
private StationDto destinationStation;
```

- `@Transient` (in `jakarta.persistence`) means "do not persist this field".
- The objects are populated at request time (in the controller/service), so the trip JSON
  can carry human-readable details instead of bare ids.
- They must **not** be `nullable=false` DB columns, and they must survive JSON serialization
  (Jackson includes them as normal properties).
- Currently absent: `Trip` has only the three id fields.

## Business meaning

A trip = "louage #X travels from station A to station B, with N seats sold at P dinars each,
currently WAITING or DEPARTED". The seat counter and the automatic transition to
`DEPARTED` when `seatsTaken` reaches the louage's capacity are **not implemented**.

## Design notes

| Topic | Note |
|---|---|
| Denormalized price | `pricePerSeat` belongs to the trip (it can change per trip/route), so storing it here is correct. |
| Missing route name/distance | not modelled; ids are enough for this project. |
| No cancellation state | `Status` has only two constants; a real system might add `CANCELLED`, `ARRIVED`. |
| No timestamps | no departure time, no creation time. |
| Money as `double` | see line 47. |
