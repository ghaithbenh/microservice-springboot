## Business meaning

A louage is a fixed-capacity shared taxi. The intended business rule (from the project
README, **not implemented yet**) is: when a trip's `seatsTaken` reaches the louage's
`capacity`, the trip becomes `DEPARTED` and the louage becomes `ON_ROAD`. Today `status` is
just a field that clients set manually, and `trip-service` never updates it.

## Design notes

- **`capacity` is a primitive `int`.** See line 39: missing JSON → 0. The controller also
  never rejects 0 or negative capacity.
- **`driverName` is duplicated state.** A real system would have a `Driver` entity or
  service; here it is a string column.
- **Unique plate = the only DB-level rule.** The controller does not check
  `existsByPlateNumber` before inserting, so a duplicate POST yields a 500
  (`DataIntegrityViolationException`), not a clean 409 Conflict.
- **No `@Version`.** Concurrent updates silently overwrite each other.
- **No `@Transient` fields** — this service returns the raw row, which is correct: enrichment
  of trips with louage details belongs to `trip-service`.
